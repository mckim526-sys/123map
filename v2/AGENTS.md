# AGENTS.md — 12·3 재판 지도 작업 지침

이 파일은 이 프로젝트에서 기능을 추가하거나 고치는 사람(과 AI 에이전트)을 위한 지침입니다.
화면 값(색·글자·간격·움직임)의 기준은 [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)에 있고, 이 파일은 **왜 그렇게 만들었는지와 지켜야 할 원칙**을 담습니다.
둘이 어긋나면 DESIGN-SYSTEM.md를 먼저 고친 뒤 코드를 맞춥니다.

## 1. 프로젝트 한눈에

- 빌드 도구 없는 정적 웹앱입니다. `index.html` + `css/` + `js/` 만으로 동작합니다.
- 실행: 프로젝트 폴더에서 `python -m http.server 5173` → `http://127.0.0.1:5173/`
  (파일을 직접 열면 스크립트 불러오기가 막힐 수 있으니 로컬 서버로 엽니다.)
- 데이터·사진은 **원본 사이트에서 직접 불러옵니다** (`js/config.js`의 `SOURCE_ORIGIN`). 로컬에 복제하지 않습니다.
  자체 데이터로 바꾸려면 `DATA_URL`·`ASSET_BASE`만 교체하면 됩니다.

## 2. 반드시 지키는 원칙

### 2-1. 화면 위계: 왼쪽 → 오른쪽 한 방향
- 왼쪽(관계도·목록·타임라인 + 상단 특검 필터·검색)이 **무엇을 볼지 정하고**, 오른쪽 상세는 고른 것을 **깊게 봅니다**.
- 오른쪽 상세는 왼쪽의 **데이터·필터·배치를 바꾸지 않습니다.** 할 수 있는 것은 "지금 이걸 보고 있다"는 **강조**뿐입니다
  (목록 행 옅은 파랑, 타임라인 해당 일정 옅은 파랑, 관계도에서 그 사건 선만 진하게).
- 반대로 왼쪽을 바꾸면 오른쪽이 따라갑니다(특검 필터를 바꾸면 상세가 그 특검 사건으로 바뀌거나 닫힘).
- 같은 것을 **두 번 누르면 취소**됩니다(선택한 사람 → 선택 해제, 고른 사건 → 강조 해제).

### 2-2. 한 화면 고정, 스크롤은 영역마다 한 곳
- 페이지 자체는 스크롤하지 않습니다. 목록·타임라인·상세 패널만 각자 안에서 세로로 스크롤합니다.
- 관계도는 스크롤 없이 그립니다. **가로 스크롤은 쓰지 않습니다**(사용성이 나쁨).
- 모바일은 관계도를 작게 줄여 고정하지 않습니다(너무 작아 읽기 어려움). 넉넉한 크기로 그리고 **손가락 끌기·벌리기로 이동·확대**합니다(`map.js`의 모바일 이동·확대 부분, `+ − 전체` 버튼).

### 2-3. 디자인 시스템만 사용
- **라이트 모드만** 지원합니다. 다크 모드 스타일을 만들지 말고, 브라우저 기본색에 기대는 요소(dialog 등)에는 배경·글자색을 직접 지정합니다.
- 색·글자 크기·간격·반경·그림자·쌓임 순서(z-index)는 `tokens.css`의 토큰만 씁니다. `app.css`에 rgba·임의 px 색을 직접 쓰지 않습니다.
- 글자는 7단계, **최소 12px**. 간격은 4의 배수.
- **카드 위·왼쪽의 색 막대, 색 테두리 + 연한 색 배경 조합 같은 장식은 쓰지 않습니다.** 강조는 옅은 회색/파랑 바탕과 굵은 글자로.
- 파란 테두리·파란 이름은 **"선택됨"** 에만 씁니다(아무것도 고르지 않은 상태에서 파랗게 보이면 안 됨).
- 선택 표시(칩·탭·뱃지)는 검정 채움으로 통일합니다.

### 2-4. 관계도 움직임
- 배치가 바뀔 때는 항상 **① 기존 선 거두기 → ② 아바타 재배치 → ③ 선 다시 그리기** 순서입니다(`animate()` 한 곳에서 처리).
- **사건만 바뀔 때는 다시 그리지 않습니다.** 선은 그대로 두고 그 사건의 선만 진하게, 나머지는 흐리게.
- 한 번의 조작에 관계도는 **한 번만** 그려야 합니다. 관계도 높이·폭에 영향을 주는 요소(범례, '○○ 중심' 줄, 상세 패널)는
  관계도를 그리기 **전에** 표시 여부를 정합니다. 그렇지 않으면 크기 감시가 한 번 더 그려 선이 깜빡입니다.
- `prefers-reduced-motion`이면 움직임 없이 결과만 보여 줍니다.

### 2-5. 내용 표기
- 관계선은 같은 사건·기소 또는 가족 관계일 뿐 **공모·유죄를 뜻하지 않습니다.** 문구도 중립적으로("핵심 인물").
- 심급 날짜 칸에는 날짜만, 사건번호는 재판부 줄 끝으로. 열리지 않은 심급(확정 이후, 항소 취하 등)은 이음선을 끊습니다.

## 3. 작업 절차

1. 화면을 바꾸기 전에 DESIGN-SYSTEM.md의 해당 항목을 읽습니다. 새 규칙이 생기면 먼저 그 문서를 고칩니다.
2. CSS·JS를 고친 뒤에는 **캐시 값을 올립니다**: `js/loader.js`의 `VERSION`과 `index.html`의 `?v=` 숫자.
3. 브라우저에서 확인합니다(데스크톱 1440×900, 모바일 390×844 두 크기 모두).
   - 콘솔 오류·경고 없음
   - 문서 가로/세로 넘침 없음(`scrollWidth - innerWidth === 0`)
   - 관계도 이름표·뱃지 겹침 없음
   - 움직임은 감으로 판단하지 말고 프레임 단위로 측정(선 거두기·재배치·선 그리기 시작 시점, 다시 그린 횟수)
4. 배포용 압축 파일을 다시 만듭니다: `python scripts/make-zip.py` (머리글의 '내려받기' 버튼이 이 파일을 내려줌).
5. 큰 구조 변경(배치 방식, 상세 흐름, 상태 연동)은 먼저 기획자에게 확인받습니다.

## 4. 시도했다가 뺀 것 (다시 넣지 않도록)

- 특검 안의 **사건 칩 필터**: 같은 사건의 피고인은 대부분 일정이 같아 의미가 적었음.
- 목록·타임라인 안의 **특검 조건 막대**: 상단 특검 칩과 중복.
- 카드 머리의 **"선택 · 이름 · 사건 ×" 칩**: 오른쪽 상세와 중복(관계도 위 '○○ 중심' 줄만 남김).
- 상세 사건 탭이 **상단 특검 필터를 바꾸는 동작**, 목록 행 내용을 바꾸는 동작: 위계 위반.
- 관계도 **가로 스크롤**, 검색창 아래 **이름 칩 목록**, **"윤석열 중심으로" 버튼**.
